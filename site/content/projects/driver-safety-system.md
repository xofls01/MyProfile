## 프로젝트 개요

영상과 생체신호를 활용해 운전자의 상태를 파악하고, 위험 상황에서 안전 대응으로 연결하는 캡스톤 팀 프로젝트입니다.

## 기본 정보

- 수행 기간: 2026년 9월~현재
- 진행 상태: 진행 중, 2026년 12월 초 종료 예정

## 프로젝트 목적

운전자가 이상 상태로 인해 직접 차량을 제어하거나 구조를 요청하기 어려운 상황에 대응하기 위한 프로젝트입니다.

영상과 생체신호를 함께 활용해 운전자 상태를 판단하고, 판단 결과를 차량의 경고·감속·정차 및 긴급 요청으로 연결하는 것을 목표로 합니다. 차량 제어는 Unity 시뮬레이션으로, 긴급 요청은 모의 관제 서버와의 연동으로 검증하고자 합니다.

## 담당 역할

팀 전체는 운전자 상태 인식부터 차량 제어와 긴급 요청까지 연결하는 시스템을 개발하고 있습니다. 저는 그중 비전 및 AI 판단 알고리즘 개발을 담당하고, 팀원들과 시나리오를 설계했습니다.

- 영상 기반 상태 인식: YOLO 등을 활용해 운전자 영상에서 행동과 자세 정보를 추출하는 알고리즘 개발
- 상태 판단 알고리즘: 영상과 생체신호를 함께 고려하는 판단 방식의 설계·개발 담당. 현재는 영상에서 추출한 특징의 지속 시간과 반복을 활용하는 판단 로직을 우선 구현
- 시나리오 설계: 팀원들과 운전자 상태와 위험 상황을 구체화하고, 데이터 수집을 위한 상황별 시나리오 설계에 참여

## 사용 기술

| 기술 | 활용 내용 |
| --- | --- |
| Python | 영상 처리와 상태 판단 로직 구현 |
| OpenCV | 영상 읽기, 프레임 처리, 분석 결과 시각화 |
| Ultralytics YOLO | 신체 키포인트 추출과 휴대전화 후보 탐지 |
| MediaPipe | 얼굴·눈·입·손의 랜드마크 추출 |
| NumPy | 좌표와 시계열 특징 계산 |

Unity와 생체신호 센서는 전체 시스템의 연동 대상이며, 현재 제공된 비전 프로토타입에는 해당 연동이 포함되어 있지 않습니다.

## 수행 과정과 방법 선택 이유

### 1. 운전자 상태별 시나리오 설계

팀원들과 운전자의 정상 상태와 주의가 필요한 행동, 위험 상황을 구체화하고 데이터 수집을 위한 시나리오를 설계했습니다.

### 2. 영상에서 행동과 자세 정보 추출

YOLO를 활용해 신체 키포인트와 휴대전화 후보를 탐지하고, MediaPipe로 얼굴과 손의 랜드마크를 추출했습니다. 이를 바탕으로 눈 감김, 고개 방향, 상체 기울어짐 등 운전자 상태 판단에 사용할 특징을 계산했습니다.

신체 자세와 물체 탐지에는 YOLO를, 눈과 입처럼 세밀한 얼굴 정보에는 MediaPipe를 활용하도록 역할을 나누었습니다.

### 3. 지속 시간과 반복을 반영한 상태 판단

순간적인 눈 감김이나 고개 움직임을 지속적인 상태 변화와 구분하기 위해, 특징이 유지되는 시간과 반복 횟수를 판단 조건에 반영했습니다.

영상에서 특징을 충분히 읽을 수 없는 경우에는 정상으로 간주하지 않고 판단 불가 상태로 구분했습니다.

### 4. 결과 시각화와 검토

영상에 추출한 특징과 판단 상태를 표시하고, 시간별 판단 근거를 로그로 저장했습니다. 결과 영상과 로그를 함께 살펴보며 어느 구간에서 상태가 바뀌었고 어떤 특징이 판단에 영향을 주었는지 확인할 수 있도록 구성했습니다.

## 현재 구현 결과

영상 기반 운전자 상태 판단 알고리즘과 Unity 시뮬레이션을 각각 1차 구현했습니다. 현재는 각 부분을 보완하고, 생체신호 및 전체 시스템 연동을 준비하고 있습니다.

제가 담당한 영상 분석 부분에서는 다음 결과를 확인할 수 있습니다.

- 분석 결과 영상: 운전자의 얼굴·자세 특징과 판단 상태를 영상 위에 표시
- 판단 근거 로그: 시간에 따른 특징값, 판단 상태와 상태 변화의 근거 기록
- HTML 결과 페이지: 분석 영상과 기록을 모아 검토할 수 있는 화면 구성

Unity 시뮬레이션은 팀에서 구현한 차량 제어 부분에 해당합니다. 현재는 영상 판단 알고리즘과 별도로 구현된 단계이며, 생체신호를 판단 알고리즘에 연결한 뒤 Unity 및 e-Call 모의 긴급 요청과 순차적으로 연동할 예정입니다.

## 한계와 개선 방향

### 생체신호 품질 보완

현재 생체신호 센서에서 얻는 신호의 품질이 충분하지 않아, 운전자 상태 판단에 활용하기 위한 보완 방법을 고민하고 있습니다.

대안으로 1학기 연구실에서 다뤘던 영상 기반 비접촉 심박 측정 기술인 rPPG를 활용하는 방안도 검토하고 있습니다. 센서를 대체하거나 보완할 수 있는지 확인하기 위해 촬영 조건과 움직임에 따른 신호 품질 및 심박 추정 결과를 검증할 계획입니다.

### 전체 시스템 연동

영상 판단 알고리즘과 Unity 시뮬레이션은 각각 1차 구현한 단계이며, 전체 시스템으로 연결하는 작업이 남아 있습니다.

각 부분을 보완한 뒤 생체신호를 상태 판단 알고리즘에 연결하고, 통합된 판단 결과를 Unity 차량 제어와 연동할 계획입니다. 마지막으로 e-Call 모의 긴급 요청을 연결해 상태 인식부터 안전 대응까지의 전체 흐름을 확인하고자 합니다.
