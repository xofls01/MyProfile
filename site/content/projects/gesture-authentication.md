## 프로젝트 개요

손·수어 제스처를 활용해 모바일 환경에서 사용자를 인증하는 비접촉 인증 시스템으로, WITECK 공모전에 참여한 팀 프로젝트입니다.

## 기본 정보

- 수행 기간: 2026년 5월~9월
- 진행 상태: 활동 종료

## 프로젝트 목표

사용자가 등록한 손 제스처를 비접촉 인증 수단으로 활용하고자 했습니다.

이를 위해 두 가지를 함께 확인해야 했습니다. 등록한 제스처와 같은 동작인지, 그리고 그 동작을 수행한 사람이 등록한 본인인지입니다. 다른 사람이 같은 제스처를 따라 하더라도 구별할 수 있는 인증 방식을 만드는 것이 목표였습니다.

## 담당 역할

팀원들과 함께 제스처 영상을 수집하고, 수집한 데이터를 활용한 AI 모델 개발을 맡았습니다.

영상에서 손 좌표를 추출하고 모델 입력에 맞게 전처리했으며, 여러 모델을 학습하고 인증 결과를 비교했습니다. 특히 등록한 사용자와 같은 제스처를 따라 하는 타인을 얼마나 잘 구별하는지 확인하는 데 집중했습니다.

앱과 서버를 포함한 전체 시스템은 팀원들과 역할을 나누어 개발했습니다.

## 사용 기술

| 기술 | 사용한 부분 |
| --- | --- |
| Python | 데이터 전처리와 모델 학습·평가 |
| MediaPipe Hands | 영상에서 손의 관절 좌표 추출 |
| NumPy | 좌표와 움직임 특징 계산 |
| PyTorch | 1D-CNN 계열 모델 구현과 학습 |
| scikit-learn | 초기 모델 비교와 성능 평가 |

## 개발 과정

### 데이터 수집과 정리

팀원들과 손 제스처 영상을 촬영하고, 수행자와 촬영 날짜를 구분해 정리했습니다. 본인이 제스처를 수행한 영상과 다른 사람이 같은 제스처를 따라 한 영상을 함께 수집했습니다.

### 손 모양과 움직임을 모델 입력으로 변환

MediaPipe Hands로 손 좌표를 추출한 뒤, 촬영 위치와 손 크기에 따른 차이를 줄이도록 정규화했습니다. 영상마다 다른 길이도 일정하게 맞췄습니다.

손 모양만으로 놓칠 수 있는 움직임의 차이를 반영하기 위해 좌표와 속도 정보를 함께 사용했습니다.

### 모델 비교와 인증 방식 개선

여러 기준선 모델을 비교한 뒤, 시간에 따른 손 움직임을 학습하는 1D-CNN 계열 모델과 임베딩 기반 인증 방식을 실험했습니다.

등록한 제스처에서 얻은 특징과 새로 촬영한 제스처의 특징을 비교해 본인 여부를 판단했습니다. 이후에는 제스처가 맞는지 확인하는 부분과 사용자가 본인인지 확인하는 부분을 나누어 모델을 개선했습니다.

### 인증 오류 분석

본인이 올바른 제스처를 수행하는 경우뿐 아니라, 본인이 다른 제스처를 하거나 타인이 같은 제스처를 따라 하는 경우도 확인했습니다.

단순히 동작을 잘 구분하는 모델이 실제 인증에서도 좋은 결과를 내는 것은 아니었기 때문에, 타인이 통과하는 경우와 본인이 거부되는 경우를 나누어 평가했습니다.

## 개발 결과

제스처 인식과 사용자 구분을 위한 AI 모델을 개발하고, 서버에서 사용할 수 있도록 모델과 사용 문서를 정리했습니다.

주요 산출물은 다음과 같습니다.

- 손 좌표 추출과 데이터 전처리 코드
- 모델 학습·평가 코드와 학습된 모델
- 등록 데이터와 인증 시도를 비교한 평가 기록
- 서버 연동을 위한 입력·출력 형식과 모델 사용 문서

## 한계와 개선 방향

### 같은 제스처를 따라 하는 타인 구분

타인이 등록자의 제스처를 비슷하게 따라 했을 때 인증을 통과하는 사례가 남아 있었습니다. 이를 줄이려면 모방 동작 데이터를 더 수집하고, 구별하기 어려운 사례를 학습에 반영할 필요가 있습니다.

### 새로운 사용자와 환경에 대한 검증

학습에 없던 사용자나 다른 촬영 환경에서는 결과가 달라질 수 있습니다. 다양한 사용자와 촬영 조건을 확보하고, 실제 모바일 환경에서 검증 범위를 넓히는 것이 필요합니다.

### 인증 기준 조정

인증 기준을 엄격하게 하면 타인의 통과를 줄일 수 있지만, 본인도 거부될 수 있습니다. 타인 수락률인 FAR과 본인 거부율인 FRR을 함께 확인하며 사용 목적에 맞는 기준을 정해야 합니다.
